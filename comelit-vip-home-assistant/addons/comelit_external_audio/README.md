# Comelit ViP · External Audio

Optional Antisip/Asterisk gateway for the Comelit ViP Native integration and Loxone. Native intercom control remains in HA; Loxone is the conversation UI.

Read the **Documentation** tab before starting. Requires the native integration, an Antisip account, your HA LAN address and a matching gateway key. One conversation at a time.

**Automatic mode accepts anonymous external SIP callers who know your address.** It does not identify individual Loxone users. It is disabled by default in the integration.
